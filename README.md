# FixWeatherGadget
**A simple and lightweight tool to revive the weather gadget on 32-bit and 64-bit versions of Windows Vista and Windows 7.**

<img width="972" height="632" alt="Zrzut ekranu 2026-10-31 061638" src="https://github.com/user-attachments/assets/c6615225-7022-4790-b4e5-545afc3d7480" />

###
**Compatibility:**
- Windows Vista RTM-SP2 (all editions, 32-bit and 64-bit)
- Windows 7 RTM-SP1 (all editions, 32-bit and 64-bit)

*(Might work on Windows Server 2008 and later as well as on Windows 8 and later if that gadget will be installed. However, it wasn't tested on these systems.)*
###
**Usage**: Run **FixWeatherGadget.exe** and click **Apply fix**. No installation required, fully portable.
